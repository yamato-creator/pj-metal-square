# ⑦ スプシからの売却入力セットアップ手順

見積もり依頼を受けた後、スクエア担当者がスプシで確定した売却情報を入力すると、資産が減算されユーザーに売却完了メールが送信される機能。

## セットアップ

### 1. 「売却入力」シートを作成

**方法A: スクリプト実行（推奨）**

まずスプシオーナーがサービスアカウントに編集権限を付与:
`pj-metal@perfect-atrium-444314-p1.iam.gserviceaccount.com`

付与後、プロジェクトルートで:
```bash
python3 setup_sale_input_sheet.py
```

**方法B: 手動作成**

スプシで「売却入力」シートを作成し、以下の構造で配置:

| 列 | A | B | C | D | E | F | G | H | I |
|---|---|---|---|---|---|---|---|---|---|
| 1行目 | # | 管理者は記入不可 | 管理者が記入 | | | | | | 管理者は記入不可 |
| 2行目 | | 貴金属 | 1. 売却量(g) | 2. 買取単価(円/g) | 日付 | 3. ユーザーID | ユーザー名 | 備考 | 4. 売却確定 |
| 3行目 | 1 | 金 | | | | | | | |
| 4行目 | 2 | パラジウム | | | | | | | |
| 5行目 | 3 | 銀 | | | 日付 | ユーザーID | (自動) | (自動) | 未確定 |
| 6行目 | 4 | プラチナ | | | | | | | |

I5セルに「未確定/確定」のドロップダウン（データ入力規則）を設定。

### 2. GASに `売却入力処理.gs` をデプロイ

スプシ連動のGASプロジェクト（`シートに入力した時.gs` があるプロジェクト）に、同梱の `売却入力処理.gs` を新規ファイルとして追加。

**※ onEditの変更点**: `シートに入力した時.gs` の onEdit 冒頭に、売却入力シートへの分岐が既に追加されているので、そのまま貼り直す。

## 使い方（運用フロー）

1. ユーザーがWebフロントで「見積もり依頼」ボタンを押す
2. 管理者メールに依頼通知が届く
3. 担当者がユーザーと単価を調整（LINE/電話など）
4. スプシ「売却入力」シートで売却内容を入力:
   - C列: 売却量(g)
   - D列: 買取単価(円/g)
   - E5: 日付（空白なら当日）
   - F5: ユーザーID → G5・H5 自動補完
5. I5で「確定」を選択 → 資産減算 + transaction記録 + ユーザーにメール

## 注意事項

- 売却量と単価はペアで入力（片方だけだとエラー）
- 保有量を超える売却量はエラー
- 同時に複数金属を一括売却可能
- 過去日付の入力可（時刻は 00:00:00 で記録）
- 「確定」後は入力欄が自動クリア
